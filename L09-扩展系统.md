## 知识点清单

1. 扩展 = 工厂函数 (pi: ExtensionAPI) => void
2. 事件监听（tool_call / tool_result）
3. 自定义工具注册
4. 状态管理（内存态 vs 持久态）
5. UI 交互（confirm 对话框）
6. 扩展上下文（ExtensionContext）

## 详细讲解

### 1. 扩展的基本结构

```typescript
// 扩展是一个工厂函数
function createMyExtension(pi: ExtensionAPI): void {
  // 注册事件监听器
  pi.on("tool_call", async (event, ctx) => {
    // 处理工具调用
  });

  // 注册自定义工具
  pi.registerTool({
    name: "myTool",
    label: "My Tool",
    description: "工具描述",
    parameters: { /* ... */ },
    execute: async (toolCallId, params) => {
      // 工具逻辑
    },
  });
}
```

### 2. 事件监听

```typescript
// 监听工具调用
pi.on<ToolCallEvent>("tool_call", async (event, ctx) => {
  console.log(`工具调用: ${event.toolName}`);
  console.log(`参数: ${JSON.stringify(event.input)}`);

  // 可以返回阻止执行
  return { block: true, reason: "危险命令" };
});

// 监听工具结果
pi.on<ToolResultEvent>("tool_result", async (event, ctx) => {
  console.log(`工具结果: ${event.toolName}`);
  console.log(`是否错误: ${event.isError}`);
});
```

### 3. 自定义工具注册

```typescript
pi.registerTool({
  name: "wordcount",
  label: "WordCount",
  description: "统计文件的行数/词数/字符数",
  parameters: {
    type: "object",
    properties: {
      path: { type: "string", description: "目标文件路径" },
    },
    required: ["path"],
  },
  async execute(toolCallId, params) {
    // 工具逻辑
    return {
      content: [{ type: "text", text: "结果" }],
      details: { lines: 100 },
    };
  },
});
```

### 4. 状态管理

```typescript
// 内存态（会话内有效）
pi.setState("callCount", 0);
const count = pi.getState("callCount");

// 持久态（跨会话有效）
pi.appendEntry({
  type: "custom",
  customType: "session_start",
  content: "会话开始",
});
```

### 5. UI 交互

```typescript
interface ExtensionContext {
  ui: {
    confirm: (title: string, message: string) => Promise<{ confirmed: boolean }>;
  };
}

// 在事件处理器中使用
pi.on("tool_call", async (event, ctx) => {
  if (isDangerous(event)) {
    const result = await ctx.ui.confirm("警告", "确定要执行吗？");
    if (!result.confirmed) {
      return { block: true, reason: "用户拒绝" };
    }
  }
});
```

### 6. ExtensionAPI 完整接口

```typescript
interface ExtensionAPI {
  // 事件系统
  on<T>(event: string, listener: (event: T, ctx: ExtensionContext) => Promise<any>): void;

  // 工具注册
  registerTool(tool: ToolDefinition): void;

  // 状态管理
  setState(key: string, value: any): void;
  getState(key: string): any;

  // 持久化
  appendEntry(entry: any): void;
}
```

## 例题

**题目**：实现一个扩展，在每次工具调用前检查是否是危险命令，如果是则弹出确认框。

**参考答案**

```typescript
function createSafetyExtension(pi: ExtensionAPI): void {
  const DANGEROUS_PATTERNS = [
    /rm\s+-rf/,
    /DROP\s+TABLE/,
    /DELETE\s+FROM/,
    /format\s+[cC]:/i,
  ];

  pi.on<ToolCallEvent>("tool_call", async (event, ctx) => {
    if (event.toolName !== "bash") return;

    const command = String(event.input.command ?? "");
    const isDangerous = DANGEROUS_PATTERNS.some(p => p.test(command));

    if (isDangerous) {
      const result = await ctx.ui.confirm(
        "⚠️ 危险命令检测",
        `检测到可能的危险命令：\n${command}\n\n确定要执行吗？`
      );

      if (!result.confirmed) {
        return { block: true, reason: "用户拒绝执行危险命令" };
      }
    }

    return undefined;  // 放行
  });

  // 记录所有工具调用
  pi.on<ToolCallEvent>("tool_call", async (event) => {
    const count = pi.getState("toolCallCount") ?? 0;
    pi.setState("toolCallCount", count + 1);

    pi.appendEntry({
      type: "custom",
      customType: "tool_call_log",
      content: `${event.toolName}: ${JSON.stringify(event.input).slice(0, 100)}`,
    });
  });
}
```
