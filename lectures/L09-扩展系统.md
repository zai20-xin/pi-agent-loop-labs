## 1. 扩展的基本结构

### 1.1 扩展定义

扩展是一个工厂函数，接收 `ExtensionAPI` 并通过它注册事件监听器、工具、命令等：

```typescript
// ExtensionFactory 类型定义
type ExtensionFactory = (pi: ExtensionAPI) => void | Promise<void>;

// 扩展可以是工厂函数或带配置的对象
type InlineExtension =
  | ExtensionFactory
  | {
      name: string;        // 显示名（如 <inline:my-ext>）
      factory: ExtensionFactory;
      hidden?: boolean;    // 隐藏启动列表
    };

// 基本扩展结构
function createMyExtension(pi: ExtensionAPI): void {
  // 注册事件监听器
  pi.on("tool_call", async (event, ctx) => {
    // 处理工具调用
  });

  // 注册自定义工具
  pi.registerTool({
    name: "myTool",
    label: "My Tool",
    description: "工具描述",
    parameters: { /* ... */ },
    execute: async (toolCallId, params, signal, onUpdate, ctx) => {
      // 工具逻辑
    },
  });
}
```

### 1.2 Extension 完整结构（内部表示）

```typescript
interface Extension {
  path: string;                    // 扩展路径
  resolvedPath: string;            // 解析后的完整路径
  hidden?: boolean;                // 是否在启动列表中隐藏
  sourceInfo: SourceInfo;          // 来源信息（本地/内联等）
  handlers: Map<string, HandlerFn[]>;  // 事件处理器
  tools: Map<string, RegisteredTool>;  // 注册的工具
  messageRenderers: Map<string, MessageRenderer>;  // 消息渲染器
  markdownTransformer?: MarkdownTransformer;       // Markdown 变换器
  entryRenderers?: Map<string, EntryRenderer>;     // Entry 渲染器
  commands: Map<string, RegisteredCommand>;        // 注册的命令
  flags: Map<string, ExtensionFlag>;               // CLI Flag
  shortcuts: Map<KeyId, ExtensionShortcut>;        // 快捷键
}
```

## 2. ExtensionContext 完整 API

### 2.1 基础属性

ExtensionContext 是事件处理器和工具执行时传入的上下文对象，包含 UI 方法、模型信息、会话管理等：

```typescript
interface ExtensionContext {
  /** UI 方法用于用户交互 */
  ui: ExtensionUIContext;

  /** 当前运行模式：tui（交互终端）、rpc（远程）、json（JSON输出）、print（打印） */
  mode: ExtensionMode;

  /** 是否有可用的对话 UI（true 在 TUI 和 RPC 模式下） */
  hasUI: boolean;

  /** 当前工作目录 */
  cwd: string;

  /** 会话管理器（只读） */
  sessionManager: ReadonlySessionManager;

  /** 模型注册表，用于 API Key 解析 */
  modelRegistry: ModelRegistry;

  /** 当前模型（可能 undefined） */
  model: Model<any> | undefined;

  /** 当前会话可用的模型列表（来自 --models / enabledModels 设置） */
  scopedModels: readonly ScopedModel[];

  /** 当前思考级别（thinking level） */
  thinkingLevel?: ThinkingLevel;

  /** Agent 是否空闲（未在流式输出） */
  isIdle(): boolean;

  /** 项目是否被信任 */
  isProjectTrusted(): boolean;

  /** 当前 AbortSignal，Agent 未流式输出时为 undefined */
  signal: AbortSignal | undefined;

  /** 中止当前 Agent 操作 */
  abort(): void;

  /** 是否有排队等待的消息 */
  hasPendingMessages(): boolean;

  /** 优雅关闭并退出（所有上下文可用） */
  shutdown(): void;

  /** 获取当前上下文使用情况（token 数、上下文窗口、百分比） */
  getContextUsage(): ContextUsage | undefined;

  /** 触发上下文压缩（不等待完成） */
  compact(options?: CompactOptions): void;

  /** 获取当前有效的系统提示词 */
  getSystemPrompt(): string;
}
```

## 4. ExtensionRuntime（运行时状态管理）

### 4.1 Runtime 结构

ExtensionRuntime 是扩展系统的核心运行时，管理所有扩展共享的状态：

```typescript
/** Runtime = 状态 + 动作 */
interface ExtensionRuntime extends ExtensionRuntimeState, ExtensionActions {}

/** 运行时状态 */
interface ExtensionRuntimeState {
  /** CLI Flag 值映射 */
  flagValues: Map<string, boolean | string>;

  /** 队列中的 Provider 注册（加载阶段） */
  pendingProviderRegistrations: Array<{ name: string; config: ProviderConfig; extensionPath: string }>;

  /** 队列中的原生 Provider 注册（加载阶段） */
  pendingNativeProviderRegistrations: Array<{ provider: Provider; extensionPath: string }>;

  /** 断言 Runtime 未失效（替换/重载后调用会抛异常） */
  assertActive: () => void;

  /** 标记 Runtime 为失效状态 */
  invalidate: (message?: string) => void;

  /** 跟踪事件总线订阅（Runtime 失效时自动取消） */
  trackEventBusSubscription: (unsubscribe: () => void) => () => void;

  /** Provider 注册/注销（加载阶段入队，bindCore 后立即生效） */
  registerProvider: (name: string, config: ProviderConfig, extensionPath?: string) => void;
  registerNativeProvider: (provider: Provider, extensionPath?: string) => void;
  unregisterProvider: (name: string, extensionPath?: string) => void;
}
```

### 16.1 安全检查扩展

```typescript
function createSafetyExtension(pi: ExtensionAPI): void {
  const DANGEROUS_PATTERNS = [
    /rm\s+-rf/,
    /DROP\s+TABLE/,
    /DELETE\s+FROM/,
    /format\s+[cC]:/i,
  ];

  // 拦截工具调用
  pi.on<ToolCallEvent>("tool_call", async (event, ctx) => {
    if (event.toolName !== "bash") return;

    const command = String(event.input.command ?? "");
    const isDangerous = DANGEROUS_PATTERNS.some(p => p.test(command));

    if (isDangerous) {
      const result = await ctx.ui.confirm(
        "⚠️ 危险命令检测",
        `检测到可能的危险命令：\n${command}\n\n确定要执行吗？`
      );

      if (!result.confirmed) {
        return { block: true, reason: "用户拒绝执行危险命令" };
      }
    }
  });

  // 记录所有工具调用
  pi.on<ToolCallEvent>("tool_call", async (event) => {
    const count = pi.getState("toolCallCount") ?? 0;
    pi.setState("toolCallCount", count + 1);

    pi.appendEntry("tool_call_log", {
      toolName: event.toolName,
      input: event.input,
      timestamp: Date.now(),
    });
  });
}
```

## 17. 事件发射顺序

### 17.1 Agent 循环生命周期

```
1. before_agent_start     ← 用户提交 prompt
2. agent_start            ← Agent 循环开始
3. turn_start             ← 每个 Turn 开始
4. context                ← LLM 调用前（可修改消息）
5. before_provider_request ← Provider 请求前（可修改 payload）
6. before_provider_headers ← HTTP Headers 组装后
7. message_start          ← 消息开始
8. message_update         ← token-by-token 更新
9. after_provider_response ← Provider 响应后
10. message_end           ← 消息结束（可替换消息）
11. tool_execution_start  ← 工具开始
12. tool_call             ← 工具调用前（可阻止）
13. tool_execution_update ← 工具执行中
14. tool_result           ← 工具结果（可修改）
15. tool_execution_end    ← 工具执行结束
16. turn_end              ← Turn 结束
    ↓
    (如有更多 Turn，重复 3-16)
    ↓
17. agent_end             ← Agent 循环结束
18. agent_settled         ← 完全稳定
```

### 17.2 会话生命周期

```
1. session_start (reason: "startup" | "reload" | "new" | "resume" | "fork")
2. resources_discover     ← 资源发现（skill/prompt/theme 路径）
3. session_info_changed   ← 会话元数据变化
   ↓
   (正常运行)
   ↓
4. session_before_switch  ← 切换前（可取消）
5. session_before_fork    ← 分支前（可取消）
6. session_before_compact ← 压缩前（可取消）
7. session_compact        ← 压缩完成
8. session_compact_failed ← 压缩失败
9. session_before_tree    ← 树导航前（可取消）
10. session_tree          ← 树导航完成
11. session_shutdown      ← 关闭
```
