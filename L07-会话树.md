## 详细讲解

### 1. SessionEntry 类型体系

```typescript
interface BaseEntry {
  id: string;
  parentId: string | null;
  timestamp: number;
}

interface HeaderEntry extends BaseEntry {
  type: "header";
  version: number;
}

interface UserEntry extends BaseEntry {
  type: "user";
  content: string;
}

interface AssistantEntry extends BaseEntry {
  type: "assistant";
  content: string;
  stopReason: "stop" | "toolUse";
  usage?: { input: number; output: number; cost: number };
}

interface ToolResultEntry extends BaseEntry {
  type: "toolResult";
  toolCallId: string;
  toolName: string;
  content: string;
  isError: boolean;
}

type SessionEntry = HeaderEntry | UserEntry | AssistantEntry | ToolResultEntry;
```

### 2. Append-Only 特性

```
原始数据：
hdr → usr1 → ass1 → tool1 → ass2
                ↓
              usr2 → ass3

特点：
- 零删除：所有历史数据都保留
- 零复制：新分支直接引用父节点
- 高效追加：只追加新条目
```

### 3. 树结构构建

```typescript
function buildTree(entries: SessionEntry[]): Map<string, SessionEntry[]> {
  const children = new Map<string, SessionEntry[]>();

  for (const entry of entries) {
    const parentId = entry.parentId ?? "root";
    if (!children.has(parentId)) {
      children.set(parentId, []);
    }
    children.get(parentId)!.push(entry);
  }

  return children;
}
```

### 4. 路径遍历

```typescript
function traversePath(entries: SessionEntry[], leafId: string): SessionEntry[] {
  const entryMap = new Map(entries.map((e) => [e.id, e]));
  const path: SessionEntry[] = [];
  let currentId: string | null = leafId;

  while (currentId) {
    const entry = entryMap.get(currentId);
    if (!entry) break;
    path.unshift(entry);
    currentId = entry.parentId;
  }

  return path;
}
```

### 5. 分支机制

```
主分支:  hdr → usr1 → ass1 → tool1 → ass2
分支点:  ass1
分支:    ass1 → usr2 → ass3
```

### 6. 成本统计

```typescript
function calculateCost(entries: SessionEntry[]): number {
  return entries
    .filter((e): e is AssistantEntry => e.type === "assistant")
    .reduce((sum, e) => sum + (e.usage?.cost ?? 0), 0);
}
```

## 例题

**题目**：实现一个函数，从会话树中提取特定分支的所有用户问题。

**参考答案**：

```typescript
function getUserQuestions(entries: SessionEntry[], leafId: string): string[] {
  const path = traversePath(entries, leafId);
  return path
    .filter((e): e is UserEntry => e.type === "user")
    .map((e) => e.content);
}
```
